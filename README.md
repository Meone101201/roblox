# Anime Expeditions - Team Builder

## 📌 เกี่ยวกับโปรเจกต์ (About The Project)
Anime Expeditions - Team Builder เป็นเว็บแอปพลิเคชัน (Web Application) สำหรับจัดทีมตัวละคร สวมใส่ไอเทม (Standard Equipment) และกำหนดนิสัย (Traits) สำหรับเกม Anime Expeditions โดยเฉพาะ ช่วยให้ผู้เล่นสามารถวางแผนการจัดทีมล่วงหน้า พร้อมทั้งคำนวณและจำลองการใส่ไอเทมต่างๆ ได้อย่างสะดวกสบาย

โปรเจกต์นี้ทำงานบนฝั่งเบราว์เซอร์ (Client-side) 100% ไม่จำเป็นต้องใช้เซิร์ฟเวอร์หลังบ้านหรือฐานข้อมูล ทำให้ทำงานได้รวดเร็ว ปลอดภัย และสามารถโฮสต์ผ่านบริการฟรีเช่น **GitHub Pages** ได้ทันที

## ✨ ฟีเจอร์หลัก (Key Features)
- 🎭 **จัดการตัวละคร (Unit Management):** ลากและวาง (Drag & Drop) หรือคลิกเพื่อเพิ่มตัวละครเข้าสู่ทีม รองรับตัวละครระดับต่างๆ (Secret, Exclusive, Mythic, Legendary, Epic, Rare)
- ⚔️ **ระบบสวมใส่ไอเทมและนิสัย (Equipment & Traits):** 
  - ระบบตรวจสอบเงื่อนไข (เช่น อุปกรณ์ที่ใส่ได้เฉพาะตัวละครระดับ Secret/Exclusive/Mythic เท่านั้น)
  - ไอเทมประจำตัว (Unit Equipment) ที่จะผูกติดกับตัวละครมาให้โดยอัตโนมัติ
  - ระบบเลือกช่องสวมใส่แบบเจาะจง (Targeted Equipping)
- 🔗 **ระบบแชร์ทีม (Team Sharing):** สามารถคัดลอกลิงก์ URL ที่มีการเข้ารหัสข้อมูลทีมของคุณไว้ เพื่อส่งให้เพื่อนดูหรือนำไปจัดต่อได้ทันที โดยที่ข้อมูลแต่ละเครื่องจะไม่ทับซ้อนกัน
- 📸 **ส่งออกเป็นรูปภาพ (Export to Image):** บันทึกทีมที่คุณจัดไว้เป็นไฟล์ภาพ (.png) ที่มีความคมชัดสูง พร้อมรายละเอียดไอเทมและนิสัยครบถ้วน (วาดผ่านระบบ Canvas)
- 📱 **รองรับทุกอุปกรณ์ (Responsive Design):** หน้าจอสวยงามและใช้งานง่าย ทั้งบนหน้าจอคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟนมือถือ

## 🛠️ เทคโนโลยีที่ใช้ (Built With)
- **HTML5:** โครงสร้างหลักของหน้าเว็บ
- **CSS3 (Vanilla):** การตกแต่งสไตล์, แอนิเมชัน, ระบบ Grid/Flexbox และ Responsive Design แนวทาง Modern/Glassmorphism
- **JavaScript (ES6):** ลอจิกการทำงาน, การเข้ารหัส URL (Base64), ระบบ Drag & Drop และการวาด Canvas สำหรับส่งออกรูปภาพแบบไม่ต้องพึ่งไลบรารีภายนอก

## 🚀 การติดตั้งและใช้งาน (Getting Started)
เนื่องจากเป็น Static Website คุณสามารถรันโปรเจกต์นี้ได้ทันทีโดยไม่ต้องติดตั้งไลบรารีหรือเซิร์ฟเวอร์เพิ่มเติม:

1. **โคลนโปรเจกต์ (Clone the repository)**
   ```bash
   git clone https://github.com/your-username/anime-expeditions-team-builder.git
   ```
2. **เปิดใช้งาน (Run Locally)**
   เข้าไปในโฟลเดอร์โปรเจกต์และดับเบิ้ลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Firefox, Edge, Safari) 
   หรือใช้ส่วนเสริมอย่าง Live Server ในโปรแกรม VS Code ก็ได้

## 🌐 การนำขึ้นระบบออนไลน์ (Deployment - GitHub Pages)
เว็บนี้พร้อมสำหรับการนำขึ้น GitHub Pages ทันที:
1. นำโค้ดทั้งหมด (Push) ไปยัง Repository บน GitHub ของคุณ
2. เข้าไปที่หน้าเว็บ Repository นั้น แล้วไปที่แท็บ **Settings** 
3. เลือกเมนู **Pages** ทางเมนูด้านซ้าย
4. ในส่วนของ **Build and deployment > Source** ให้เลือก `Deploy from a branch`
5. ในส่วนของ **Branch** ให้เลือก `main` (หรือ `master`) แล้วคลิก **Save**
6. รอสักครู่ (ประมาณ 1-2 นาที) GitHub จะสร้างลิงก์เว็บไซต์ให้คุณโดยอัตโนมัติ (เช่น `https://<your-username>.github.io/<repository-name>/`) 
7. นำลิงก์ที่ได้ไปแชร์ให้ผู้เล่นคนอื่นใช้งานได้เลย!

## 💡 วิธีการใช้งาน (How to use)
1. **เพิ่มตัวละครลงทีม:** ไปที่แท็บ "รายการตัวละคร" เลือกระดับ (Rarity) จากนั้นลากรูปตัวละครมาวางที่ช่องในทีม หรือคลิกที่ตัวละคร (ระบบจะส่งไปที่ช่องว่างที่ใกล้ที่สุด)
2. **สวมใส่ไอเทม/Traits แบบเจาะจง:** 
   - ให้นำเมาส์ไปคลิกที่ช่อง "ไอเทม" หรือช่อง "Trait" ว่างๆ ของตัวละครในทีม (ช่องจะมีกรอบสีทองปรากฏขึ้น)
   - ไปที่แท็บ "รายการ Standard Equipment" หรือ "Traits" แล้วคลิกไอเทมที่ต้องการ ระบบจะส่งไอเทมไปใส่ในช่องที่เลือกไว้ทันที
3. **การถอดไอเทม:** สามารถดับเบิ้ลคลิก (Double-click) ที่รูปไอเทมในตัวละคร เพื่อถอดออกได้ทันที
4. **ส่งออกเป็นรูป:** กดปุ่ม `ส่งออกรูปภาพ` (สีม่วง) ด้านขวาบนสุด ระบบจะสร้างรูปภาพรวมทีมของคุณ ให้กดปุ่มดาวน์โหลดเพื่อเซฟลงเครื่อง
